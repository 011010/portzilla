FOR PARALLEL CODING AGENTS

Every collision
has an owner.

Ports, files and worktree environments do not know about your parallel sessions. portzilla makes ownership explicit — then enforces it, before an agent kills a process or overwrites a file it does not own.

THREE LAYERS

Same question,
three resources.

Each layer answers who owns this right now? The guard is the part that makes the answer binding.

01

Ports

lease

A claim records the owning process and its purpose. A conflict reassigns forward instead of stealing. The guard blocks kill, pkill, lsof | xargs kill, fuser -k and kill-port against a live foreign lease.

portzilla claim 3000 --tag next-dev

02

Files

intent

The first session to edit a file claims it. A peer's edit is proven against the holder's copy with a real three-way merge: clean is allowed with a warning the model reads; a conflict is denied before the write. Hooks on OpenCode and Claude Code; the same verdicts over MCP everywhere else.

portzilla intent who src/auth.ts

03

Environments

slot

A slot gives one worktree its own named ports, cache directories, .env.portzilla, and a database provisioned by your own commands. Creation is transactional; teardown refuses to destroy a database it could not deprovision.

portzilla slot up auth

THE GUARD

Deny only when
the merge is real.

ConditionVerdictWhat happens
the pending edit merges cleanly allow the holder keeps the claim, and the model reads a warning on the tool result
the pending edit conflicts deny the reason names the holder and the conflicting version; nothing is written
cleanliness cannot be proven deny the behaviour the guard always had — an old record, a git failure, an incomplete payload

The guard only relaxes when cleanliness is proven, never when it is merely unknown.

NON-GOALS

What it refuses
to become.

✕

No daemon

Every claim is a file-locked JSON write. Nothing to keep running or restart.

✕

No containers

Slots prepare an environment; they do not own your Compose stack.

✕

No secrets

Provisioning runs your commands with your environment. portzilla passes names and paths.

✕

No cross-machine magic

Claims are local to one data directory, on one machine, by design.
