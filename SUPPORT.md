# Support

## Questions and Usage Help

Use GitHub Discussions for questions about installation, configuration, MCP setup, hook integrations, and normal CLI usage. Search existing discussions and the documentation before opening a new thread.

## Bug Reports

Use the bug report issue template when behavior is reproducibly incorrect. Include the Portzilla version, operating system, command, relevant configuration, and the smallest useful reproduction.

Do not publish secrets, private state files, or sensitive command arguments. Redact them before posting logs.

## Feature Requests

Use the feature request template. Explain the problem first, then describe the desired behavior and alternatives considered.

Security issues must be reported privately as described in [`SECURITY.md`](SECURITY.md).
